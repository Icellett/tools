# ЛР 4Б — контракт TutBerry API

Файл [openapi.yaml](openapi.yaml) — начальное описание **уже реализованного** `POST /api/bookings`. Исходный перечень операций и целевых ролей ЛР 2Г находится в [resources.md](resources.md).

## Важное расхождение

В ЛР 2Г запланированы `/api/v1`, JWT, единые ошибки и множество ресурсов. В ЛР 3 реализован лишь `POST /api/bookings` с аутентификацией DRF. Пока нельзя утверждать, что реализованы JWT, остальные операции или RFC 9457. Следующие шаги ЛР 4Б — согласовать целевой контракт, реализовать единые ошибки и защиту, затем автоматизировать проверку соответствия.

Изменения в контракте вносятся вместе с реализацией и тестами. Несовместимые изменения требуют новой версии API.
