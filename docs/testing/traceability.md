# Матрица прослеживаемости обязательных требований (ЛР 5)

Источник приоритетов: [docs/requirements.md](../requirements.md), раздел 11 «Приоритизация MoSCoW». **Must: FR-01, FR-02, FR-06, FR-07.** Матрица фиксирует проверку каждого требования, но не выдаёт планируемые тесты за пройденные.

| Требование Must | Проверка / критерий | Связанный тест или план | Состояние |
| --- | --- | --- | --- |
| FR-01 — поиск и фильтрация | Из 10 объявлений с одним занятым вернуть 9; фильтры по датам, цене, локации и категории | `docs/testing/test-design.md`, раздел 6; будущий API-тест поиска | **Не реализовано**: endpoint поиска отсутствует |
| FR-02 — расчёт цены и залога | Ставка × дни + залог; сервер возвращает rent/deposit/total | `tests/test_booking_service.py`, `tests/test_booking_domain.py`, TD-08 | **Частично проверено**: серверный расчёт; UI до бронирования не проверен |
| FR-06 — объявление и модерация | Создание с обязательными полями, статус модерации, ограничения прав | `tests/test_booking_domain.py::test_listing_moderation`; TD для HTTP/UI требуется дополнить | **Частично проверено**: доменное правило, не весь пользовательский сценарий |
| FR-07 — заявка и решение владельца | Создание заявки на свободные даты, отказ при пересечении, решение владельца | `tests/test_booking_api.py`, `tests/test_booking_domain.py::test_booking_lifecycle_and_cancelled_guard`, TD-12–TD-25 | **Частично проверено**: создание и доменные переходы; полный API-сценарий решения владельца не подтверждён |

**Прослеживаемость (наличие указанного способа проверки): 4/4 Must, 100%.**

**Подтверждённая полная реализация и автоматическая проверка всех критериев Must: не достигнута.** Эта цифра не равна 100% функционального покрытия. Для FR-01 необходимы реализация поиска и интеграционный тест, для остальных — оставшиеся приёмочные проверки.

Сверка с методичкой: правило прослеживаемости в CI должно требовать наличия записи и непустой проверки для каждого Must. Оно **не должно** автоматически объявлять требование выполненным только по наличию текста.
