## Что ещё не подтверждено

1. **Защита ветки:** в доступных действиях GitHub нет настройки branch protection/rulesets, поэтому нельзя подтвердить, что GitHub *запрещает слияние* при красном CI. Наличие CI не равно включённой защите. В настройках репозитория администратор должен открыть **Settings → Rules → Rulesets** (или **Settings → Branches**), установить правило для целевой ветки, включить требование успешных status checks и выбрать `quality-and-tests` (проверить фактическое имя check в интерфейсе).
2. **NFR-01 поиска:** `/health` не является поиском. Для полноценного подтверждения нужны реализованный endpoint, 50 000 активных объявлений, k6 на 20 запросов/с и записанный p95 ≤300 мс.
3. **Функциональность Must:** карта содержит 4/4 связей с проверками, но FR-01 и часть других критериев пока не реализованы целиком.
4. **Точные показатели:** необходимо извлечь измеренный процент покрытия ветвей и JSON-отчёты k6, если нужны для защиты работы.
5. **Разбор выживших мутаций:** девять мутаций остаются; достигнутый порог 70% не требует их обязательного устранения.

Автоматизированные проверки методички настроены и по доступным подтверждениям успешно проходят; мутационный балл **82,7%**.
