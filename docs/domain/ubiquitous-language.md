# Единый язык предметной области — TutBerry

Единые названия используются в требованиях, модели предметной области и архитектурной документации.

| Термин | Имя в коде | Значение | Контекст |
|---|---|---|
| Пользователь | `User` | Зарегистрированный участник платформы | Учёт пользователей |
| Арендатор | `Tenant` / роль `tenant` | Пользователь, берущий инструмент | Учёт пользователей |
| Владелец инструмента | `Owner` / роль `owner` | Пользователь, публикующий объявление | Учёт пользователей |
| Модератор | роль `platform` | Пользователь с правом проверки и разрешения споров | Учёт пользователей |
| Объявление | `Listing` | Предложение аренды инструмента с ценой и статусом | Каталог |
| Статус объявления | `ListingStatus` | `draft`, `moderation`, `active`, `archived` | Каталог |
| Блокировка дат | `BlockedPeriod` | Даты, вручную исключённые владельцем из доступности | Каталог |
| Бронь / заявка | `Booking` | Запрос аренды конкретного объявления на период | Бронирование |
| Период аренды | `RentalPeriod` | Начальная и конечная календарные даты | Бронирование |
| Статус брони | `BookingStatus` | Состояние заявки/сделки: `pending`, `approved`, `paid`, `active`, `completed`, `cancelled`, `disputed` | Бронирование |
| Стоимость аренды | `BookingPrice` | Зафиксированная сумма аренды на выбранный период | Бронирование |
| Залог | `DepositAmount` | Сумма обеспечения возврата инструмента | Бронирование / Платежи |
| Платёж | `Payment` | Финансовый процесс по брони, подтверждаемый провайдером | Платежи |
| Платёжная операция | `Transaction` | Отдельное удержание, оплата, возврат или выплата | Платежи |
| Спор | `Dispute` | Разбирательство по конкретной сделке | Бронирование / Модерация |

## Слова, которые не смешиваются

| Неоднозначная формулировка | Используем | Почему |
|---|---|---|
| «Товар» и «вещь» как запись каталога | «Объявление» (`Listing`) | Объявление — запись платформы, инструмент — физический предмет |
| «Заявка» и «бронь» как разные объекты | `Booking` с состоянием `pending` | В текущей ER-модели одна таблица `BOOKINGS` |
| «Оплата прошла» по нажатию кнопки | «Платёж подтверждён провайдером» | Нажатие кнопки не доказывает списание |
| «Вернул» как автоматическое разрешение спора | «Возврат отмечен» | Отметка возврата не равнозначна решению по спору |
| `ListingData`, `BookingManager`, `PaymentHelper` | `Listing`, `Booking`, `Payment`, `BookingService` | Имена отражают предметную область, а не техническую оболочку |

## Проверка трёх совпадений

| Термин | Требования / USM | Агрегаты | События |
|---|---|---|---|
| `Listing` | FR-06, US-01 | `Listing` | `ListingCreated`, `ListingApproved` |
| `Booking` | FR-07, US-05/US-06 | `Booking` | `BookingCreated`, `BookingApproved` |
| `Payment` | FR-03, US-07/US-11 | `Payment` | `PaymentConfirmed`, `DepositReleased` |
