# TutBerry — Автоматизированная информационная система аренды инструментов

**TutBerry** — это цифровая платформа-маркетплейс для безопасной и прозрачной аренды инструментов и оборудования между частными лицами. Система минимизирует риски мошенничества за счет использования эскроу-счетов (заморозки залога), системы рейтингов, встроенного чата и ручной модерации объявлений.

Проект разработан в рамках дисциплины «Системный анализ».

## 📌 Основные возможности (MVP)
*   **Для Владельца инструмента:** Создание объявлений, управление календарем доступности, подтверждение/отклонение заявок на бронирование, получение оплаты.
*   **Для Арендатора:** Поиск инструментов по фильтрам, просмотр рейтингов и отзывов, оформление заявки, безопасная оплата аренды и залога (эскроу), возврат вещи.

## 🛠 Технологический стек
*   **Backend:** Python 3.11+, Django, PostgreSQL 14+
*   **Frontend:** React 18, TypeScript
*   **Инфраструктура:** Docker, Nginx
